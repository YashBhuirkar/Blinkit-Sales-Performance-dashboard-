# Blinkit Sales Analysis Dashboard (Power BI)

## Project Overview
This project analyzes Blinkit retail sales data using Power BI to understand product performance, outlet sales, and customer demand patterns.

The dashboard provides interactive insights into sales distribution, product categories, outlet performance, and key business metrics to support better business decisions.

---

## Objectives
- Analyze Blinkit sales performance across different outlets.
- Understand product category contribution to total sales.
- Evaluate outlet size, location, and type impact on revenue.
- Identify trends in product demand and customer purchasing patterns.

---

## Dataset Description
The dataset contains sales and outlet information including:

- Item Identifier
- Item Type
- Item Fat Content
- Item Visibility
- Item Weight
- Outlet Identifier
- Outlet Size
- Outlet Location Type
- Outlet Establishment Year
- Sales
- Rating

These attributes help analyze product performance and outlet efficiency.

---

## Data Model
A structured data model was implemented in Power BI for efficient analysis and visualization.

Main analysis areas include:
- Product category analysis
- Outlet performance comparison
- Sales distribution across locations
- Customer rating insights

---

## Dashboard Insights

### 1. Sales Overview
Provides key metrics including:
- Total Sales
- Average Sales
- Number of Items Sold
- Average Rating

### 2. Product Category Analysis
Analyzes how different item categories contribute to total sales.

### 3. Outlet Performance
Compares sales performance across:
- Outlet types
- Outlet sizes
- Outlet locations

### 4. Outlet Establishment Trend
Analyzes sales distribution based on outlet establishment year to understand business growth patterns.

---

## Key Insights
The dashboard helps identify:

- Top performing product categories
- Outlet locations generating the highest revenue
- Impact of outlet size on sales performance
- Customer rating trends across products
